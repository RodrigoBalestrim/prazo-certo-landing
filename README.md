# Prazo Certo — Landing Page

Landing page oficial do [Prazo Certo](https://prazo-certo.expo.app), aplicativo multiplataforma
para controle de validade de produtos. Construída com **Next.js**, **React**, **TypeScript** e **Tailwind CSS**.

## Seções

- Hero com chamada para teste do aplicativo
- Recursos: leitor de código de barras, alertas por setor, PDF, grupos de empresa, IA
- Stack completa do projeto
- CTA e links para código-fonte

## Stack

- Next.js (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Deploy: Vercel

## Rodar local

```bash
npm install
npm run dev
```

Abra http://localhost:3000.
